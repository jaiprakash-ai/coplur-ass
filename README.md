# Python Assessment

This repository contains solutions for two programming problems.

## Problem 1: First Non-Repeating Character

Given a string, find the first character that appears exactly once.

### Example

Input:
swiss

Output:
w

### Complexity

- Time Complexity: O(n)
- Space Complexity: O(n)

## Problem 2: Find the Missing Number

Given an array containing N distinct numbers from 1 to N+1, find the missing number.

### Example

Input:
1 2 4 5 6

Output:
3

### Complexity

- Time Complexity: O(n)
- Space Complexity: O(1)
